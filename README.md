# Publishque

Publishque is a social media post scheduling platform for managing and automating posts across Facebook, X/Twitter, LinkedIn, and Pinterest.

## Setup

1. Clone the repository.
2. Create your local environment file:

   ```bash
   cp .env.example .env
   ```

3. Start the application:

   ```bash
   docker-compose up
   ```

The Django app will be available at `http://localhost:8000/`.
